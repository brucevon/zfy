# zfy — TriliumNext Blog Theme

<p align="center">
  <a href="README.md">中文</a> · <a href="README.en.md">English</a>
</p>

> zfy is a TriliumNext blog theme using a **server-side realtime aggregation (SSR)** approach: the template walks the note tree on every render to build the homepage, category tree, About menu, tag cloud, heatmap and title search index. **Edit and it's live — no snapshot rebuild needed.**
>
> AI-assisted documentation, verified manually. When in doubt, the code is authoritative.

## Features

| Feature | Description |
|---|---|
| Two-column layout | Left: announcements/updates/heatmap; right: latest articles; single column on mobile |
| Realtime aggregation | Template walks the note tree at render time; edit and it's instantly live, no json snapshot |
| Tag-driven | Homepage/categories/tag-cloud/comments/footer/cover all label-driven, zero hardcoding |
| Dual theme | CSS variables + `data-theme`; one-click dark/light switch |
| Title search | Server collects a realtime title index; client instant search with highlighting |
| Breadcrumbs | Category path on home cards / content pages, click to locate in category tree |
| Article pagination | Latest articles, 5 per page |
| Tag cloud | Tag aggregation + per-tag article list (two columns on PC, single on mobile) |
| Image lightbox | Click to zoom, large prev/next buttons, arrow-key support |
| shareAlias | Alias URLs auto-resolve to the real noteId |
| Single-file deploy | Build script inlines minified CSS/JS into one EJS |
| Zero backend reliance | All page data aggregated server-side by the template; no backend script needed |

## Architecture

### Data Flow (Server-Side Realtime Aggregation / SSR)

```text
Root note (#isHome=true)
  └─ blog.ejs walks the shared subtree at render time
       ├─ #article        → latest article list
       ├─ #announcement   → announcement card
       ├─ #recentUpdate   → updates module + menu "Recent Updates"
       ├─ #recommend      → recommendation count
       ├─ #category       → category tree + content breadcrumbs
       ├─ #noteTag        → tag cloud / module & note tags
       └─ all visible notes → title search index (window.__SSR_SEARCH__)
            └─ result renders HTML directly and injects window.__SSR_*__ for client interaction
```

- **Server render** — the four homepage modules, category tree, About menu, nav stats, breadcrumbs and heatmap are generated as HTML in the template (SEO-friendly, edit-and-live).
- **Client interaction** — `blog.js` uses the injected `window.__SSR_HOME__ / __SSR_ARTICLES__ / __SSR_TAGDATA__ / __SSR_HUB__ / __SSR_SEARCH__ / __BLOG_CONFIG__` to handle expand/collapse, locating, search, pagination, lightbox and theming. It **no longer fetches `/blog-data` or `/blog-search`**.
- **Zero backend** — all data is aggregated by the template at render time; the repo contains no preprocessing script, deployment needs only one `blog.min.ejs`.

## Quick Start

> Note: in Trilium, "enable sharing" = right-click the note → Share, making the URL public.

### 1. Download Resources

```text
share/blog.min.ejs      # ★ single-file build (deploy; generated by build-min.js)
share/blog.ejs          # template (source, for editing)
share/css/blog.css      # styles (source)
share/js/blog.js        # script (source)
```

Twikoo is served from CDN — no need to upload `twikoo.min.js`.

### 2. Import Template (single file)

In Trilium create a `分享` (Shared) parent, then a template note with sharing enabled, and paste the `blog.min.ejs` content:

| Template note | Labels |
|---|---|
| `blog.min.ejs` | `~shareTemplate(inheritable)=blog.min.ejs` (Relation) |

> Labels starting with `~` are Relations — link them manually in the Relation Map; pasting text won't work.
> `~shareTemplate` is **required**; without it the share page won't use the theme.

### 3. Image Assets (optional)

| Image | Purpose |
|---|---|
| `logo.icon` | top avatar |
| `bg-pc.png` | PC background |
| `bg-mobile.png` | mobile background |
| `beian.png` | footer ICP icon (optional) |

Overridable via `#coverDefaultImage` / `#coverMobileImage` / `#footerBeianIcon` on the root note.

### 4. Root Note

Create a root note, enable sharing, set key labels (full list in [Labels & Config Reference](#labels--config-reference)):

- `#isHome=true`
- `#blogTitle` / `#blogDescription`
- `~shareTemplate(inheritable)=blog.min.ejs`

### 5. "About" Note

The template finds a note titled 「关于」(About) under the root note to render the About dropdown menu. Create an (optionally empty) About note; its children configured with `#category` / icons / colors become menu items.

### 6. Publish Articles / Categories

Add labels to child notes (inherit from the root note; toggle them directly on child notes):

| Label | Effect | Where |
|---|---|---|
| `#article=true` | article, into "Latest Articles" | article note |
| `#recentUpdate=true` | update, into "Updates" + menu "Recent Updates" | update note |
| `#announcement=true` | announcement (first one) | announcement note |
| `#recommend=true` | recommended, counted | article note |
| `#category=true` | category node (tree + breadcrumbs) | category note |
| `#noteTag=xxx` | tag, into tag cloud / module & note tags | any shared note |
| `#shareAlias=xxx` | alias URL (optional) | any note |
| `#shareExternalLink=...` | external link | category or article |
| `#articleCover=https://...` | cover image (home/tag-cloud card) | article |
| `#color=#hex` | title/icon color | any note |
| `#iconClass=bx bxs-xxx` | icon | any note |
| `#shareHiddenFromTree=true` | exclude from tree/search/stamping | internal notes |

> The category tree is generated from the `#category` parent-child hierarchy; a note's breadcrumb is its category path to the root.

### 7. Tag Cloud (optional)

Create a note and add `#tagCloud` (or add it as a child of the root with that label); it becomes the tag-cloud page. The homepage "View all →" and the "article/updates/recommend/announcement" counters jump to it. Use `#tagCloudIconClass` to customize the tag icon.

### 8. Create Time (optional)

A shared template can't read a note's real create time. To show "create time" on a content page, add the `#dateCreated=YYYY-MM-DD` label to the article manually (see [Labels & Config Reference](#labels--config-reference)).

## Minified Deployment

Sources are readable; the output is a single file:

```text
Sources: share/blog.ejs + share/css/blog.css + share/js/blog.js
Output:  share/blog.min.ejs (esbuild-minified css/js inlined, with version header)
```

```bash
node build-min.js   # Node ≥ 16; pulls esbuild automatically on first run
```

## nginx Reference

Production reverse proxy that hides the `/share/` prefix:

```nginx
upstream trilium { server 127.0.0.1:8080; keepalive 2; }

server {
    listen 80; server_name yourdomain.com;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl http2; server_name yourdomain.com;
    ssl_certificate /etc/nginx/ssl/yourdomain.com/cert.pem;
    ssl_certificate_key /etc/nginx/ssl/yourdomain.com/key.pem;
    ssl_session_cache shared:SSL:10m; ssl_session_timeout 10m;
    ssl_protocols TLSv1.2 TLSv1.3; ssl_prefer_server_ciphers on;

    gzip on; gzip_min_length 1k; gzip_comp_level 6;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml application/xml+rss;
    gzip_vary on;

    location ~* /(login|setup|admin|ws|custom|inside) { return 404; }

    location /share/assets/ {
        proxy_pass http://trilium;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_http_version 1.1; proxy_set_header Connection "";
        proxy_read_timeout 90;
    }
    location / {
        proxy_pass http://trilium/share/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cookie_path /share/ /;
        proxy_http_version 1.1; proxy_set_header Connection "";
        proxy_read_timeout 90;
        proxy_buffer_size 512k; proxy_buffers 4 512k;
        proxy_busy_buffers_size 1024k; proxy_max_temp_file_size 0;
    }
}
```

`location /` → `proxy_pass http://trilium/share/` hides the `/share/` prefix; static/pages share one route; security blocks target only backend paths, without touching `/api/attachments/`.

## Labels & Config Reference

> `~relation` types must be linked manually in Relation Map; all `#label:` labels belong on one line, space-separated (broken into categories below for readability — merge when pasting).

### Relations

```text
~shareTemplate(inheritable)=blog.min.ejs
```

A template note with `~shareTemplate` makes share pages use this theme (**required**). Use `blog.ejs` when debugging from source.

|---|---|---|

| `#blogDescription=` | blog subtitle / description | — |

| `#coverMobileImage=` | mobile background URL | `/bg-mobile.png` |
| `#twikooEnabled=true` | enable comments | — |
| `#twikooEnvId=` | Twikoo env id | — |
| `#twikooVersion=` | Twikoo version | `1.6.41` |
| `#footerCopyright=` | footer copyright text | — |
| `#footerIcp=` | ICP number | — |
| `#footerPolice=` | police number | — |
| `#footerPoliceUrl=` | police link | — |
| `#footerBeianIcon=` | ICP icon URL | `/beian.png` |
| `#siteStartDate=` | site start date ("running N days") | — |

### Child Note Labels (inheritable)

Exposed to all children. Toggle them directly on child notes:

| Label | Description |
|---|---|
| `#article=true` | article |
| `#recentUpdate=true` | update |
| `#announcement=true` | announcement |
| `#recommend=true` | recommended (count only notes owning it) |
| `#category=true` | category node |
| `#noteTag=<value>` | tag (multiple, into tag cloud / module & note tags) |
| `#shareAlias=<alias>` | alias URL |
| `#shareExternalLink=<url>` | external link |
| `#shareHiddenFromTree=true` | exclude from tree/search/stamping |
| `#articleCover=<image url>` | article cover |
| `#dateCreated=` | create time (optional; shows create date on content page when set) |
| `#color=<hex>` | title/icon color |
| `#iconClass=<icon class>` | icon |
| `#enableTwikoo=true` | enable comments per note |

> `#recommend` counts only notes that own the label, so inheritance doesn't count everything.

### Tag Cloud Note

| Label | Description |
|---|---|
| `#tagCloud` | mark this note as the tag-cloud page |
| `#tagCloudIconClass=` | override the tag icon class |

## FAQ

- **Blank page** — verify the root note and resources have sharing enabled; the `~shareTemplate` Relation is linked.
- **Category tree / About menu missing** — confirm an About note exists under the root; category nodes have `#category=true`.
- **Article missing on homepage** — confirm the article note has `#article=true`.
- **No "create time" on a content page** — a shared template can't read real create time; add `#dateCreated=YYYY-MM-DD` manually to the article.
- **Tag cloud not showing** — confirm the tag-cloud note has `#tagCloud` with sharing enabled; notes have `#noteTag`.
- **Broken styles** — hard refresh (Ctrl+F5); use only the single `blog.min.ejs` shared note.
- **Search finds nothing** — search matches titles only; confirm the note doesn't have `#shareHiddenFromTree` or `#category`.
